Cifrar una nueva versión del Excel

Genera el archivo tablero.enc que usa la página. Todo ocurre en este navegador: el Excel y la clave no se envían a ningún servidor.

  1. Descarga tablero.enc con este formulario.
  2. En GitHub abre la carpeta data/ del repositorio y reemplaza tablero.enc («Add file → Upload files»).
  3. En uno o dos minutos la página publicada mostrará los datos nuevos.
